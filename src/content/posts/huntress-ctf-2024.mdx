## Matryoshka QR

Warmups

<Figure src="/blog/matryoshka-qr/01.png" alt="" />

As a part of this challenge, we are given a QR code. Scanning the code gives us the data for a PNG image (as indicated by the `\x89PNG` at the start), which is just another QR code. Save the data as bytes into another PNG file and view it using an image viewer of your choice. Finally, scan the smaller QR code to get the challenge flag.

<Figure src="/blog/matryoshka-qr/02.png" alt="" caption="qrcode.png" />

## Cattle

Warmups

<Figure src="/blog/cattle/01.png" alt="" />

The file attached to the challenge is a text file containing what would appear to be random combinations of m's and o's.

<Figure src="/blog/cattle/02.png" alt="" caption={'The "code"'} />

After a bit of looking around online, I managed to find out that it was actually code in "COW", a programming language. You can learn more about it at - [https://bigzaphod.github.io/COW/](https://bigzaphod.github.io/COW/).

There happens to be an online tool to decrypt the language. Using this tool, we can get the flag to the challenge.

[https://www.cachesleuth.com/cow.html](https://www.cachesleuth.com/cow.html)

## Whamazon

Warmups

<Figure src="/blog/whamazon/01.png" alt="" />

This challenge is rather simple, but it's quite easy to overthink it. All we have to do is buy the flag from "Whamazon". The only issue is that the flag costs $10000000000 but we only have $50 to start with. So currently, with the money we have, we can't buy the flag nor the house (not that we need the house).

<Figure src="/blog/whamazon/02.png" alt="" />

<Figure src="/blog/whamazon/03.png" alt="" />

May as well buy an apple with what we have right now. Since it's only $3, we'll be left with $47.

<Figure src="/blog/whamazon/04.png" alt="" />

It looks like the store is simply multiplying the amount that we specified with the cost of an item and subtracting that "cost" from the current balance. But it might not be checking the quantity that is being specified. What if we buy a negative amount of things (say, video games in this case)?

<Figure src="/blog/whamazon/05.png" alt="" />

Well, that wasn't so hard! With the money that we now have, we can easily buy a flag (or two).

<Figure src="/blog/whamazon/06.png" alt="" />

Now, all that's left is to check the inventory for the flag.

## Finder's Fee

Warmups

<Figure src="/blog/finders-fee/01.png" alt="" />

The name and description of the challenge is a pretty big giveaway as to what you have to do to get the flag. Once we log onto the server using ssh, we can use the `ls` command to list the files/directories present in `/home`. `user` does not have permissions to read the contents of `finder`'s home directory.

<Figure src="/blog/finders-fee/02.png" alt="" />

Checking `/bin`, we see that it links to `/usr/bin`. Listing out the files, the `find` binary stands out as it has it's [SGID](https://linuxconfig.org/how-to-use-special-permissions-the-setuid-setgid-and-sticky-bits) bit set. This allows us to run the `find` command as though we were in the `finder` group.

<Figure src="/blog/finders-fee/03.png" alt="" />

<Figure src="/blog/finders-fee/04.png" alt="" />

We can use the `find` command to list out the files present in `finder`'s home directory, something that we did not have the permission to do previously.

<Figure src="/blog/finders-fee/05.png" alt="" />

We can specify the `-exec` flag to execute a command based on the result of the search. The command we will be using in this case is `cat` to print out the flag.

<Figure src="/blog/finders-fee/06.png" alt="" />
